設定
----

### 設定画面

#### ブラウザの設定画面内

ブラウザの拡張機能の設定などの項目から開かれる。
ブラウザ側で用意した領域に埋め込まれる。
実機だと特別なタブのような形。
{ openType: "browser", id: "browser" }

#### 独立したタブ

ブラウザの設定画面内の設定画面からOpen In Tabで開かれる。
独立したタブ。
{ openType: "tab", id: "tab" }

#### URLを指定したタブ

下記でクライアントや設定が存在しない場合に開かれるタブ。
クライアントの存在の有無で開かれる領域が変わる。
クライアント部分は一方向で画面遷移上戻ることは無いようにしてある。
設定が完了したらタブは閉じて元のタブにもどる。
{ openType: "url", id: URL }

#### UUIDを指定したタブ

アカウント指定領域をクリックしたときに、もし設定セットを使用していなければ開く。
使用中のクライアントの設定を開くようになっている。
{ openType: "uuid", id: UUID }

#### 設定セット用のタブ

アカウント指定領域をクリックしたときに、もし設定セットを使用していれば開く。
設定セットを選ぶとタブは閉じて元のタブにもどる。
設定セットを選んでさらに設定を編集することもできる。
{ openType: "set", id: "set" }

### クライアント

#### 新しいクライアントの作成

新しいクライアントについて下記の
「定義」「パーミッション」「個々の設定」を実行する。
基本的には順に設定していくが途中で抜けることも可能。

#### クライアントの定義

名前とURL Patternを設定する。
Nextボタンで「設定してパーミッションの設定」を続けることもできるし、
Applyで設定してCancelで抜けることもできる。
Revertで入力をクリアして元の値にもどすことができる。
また、ここから削除画面に遷移することができる。

#### クライアントの削除

クライアント削除の確認画面。
クライアント名とURL Patternが表示される。
ボタンはCancel/Delete。

#### アカウントに対するパーミッション

アカウント一覧が表示される。
それに対して、None/Get Public Key/+ Signの3つのラジオボタンから選択する。
選択された場合、すぐにデータベースに反映される。
全体のボタンとしてはExit/Nextとなる。

#### クライアントの個々の設定

この画面で一番大事なのはアカウントの選択。
ラベルはSelect Account。
またクライアントページ上にアカウント情報(名前と公開鍵)を表示するかどうか選べる。
表示する場合には位置、色、Opacity、そしてクリックで設定画面を表示するかどうかを選べる。
ボタンはRevert/Apply/Cancel/OK
